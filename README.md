## 📖 About

This project is my personal portfolio website, built to showcase my projects, learning journey, and continuous growth.

Rather than focusing only on technical skills, the portfolio highlights:

- AI Learning
- Knowledge Management
- Content Creation
- Personal Projects
- Digital Productivity
- Continuous Learning

The website follows an **Editorial Minimal Tech** direction — the typographic discipline of Swiss / International Typographic Style (12-column grid, editorial type hierarchy, hairline borders, generous whitespace) fused with a modern minimal tech feel (brand blue, clean components, responsive interactions).
